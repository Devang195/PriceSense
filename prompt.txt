- **Project Name**: PriceSense
- **Core Purpose**: An intelligent time-series forecasting and price analytics web application that tracks historical e-commerce product pricing, predicts future price trends across configurable forecast horizons (1–30 days), and benchmarks multiple ML/statistical models.
- **Tech Stack**:
  - Language: Python 3.11+
  - Web UI / Dashboard: Streamlit
  - Machine Learning & Statistics: Scikit-learn (Linear Regression, MAE, RMSE, R²), Statsmodels (Holt's Linear Trend / Exponential Smoothing, ARIMA(1,1,0)), NumPy

  - Package Management: uv / pyproject.toml
- **Core Architecture & Features**:
  1. **Automated Web Scraper (`scraper/scraper.py`)**: Gathers live product prices from e-commerce catalog targets (with User-Agent headers, polite delays, schema validation, and incremental deduplication).
  2. **Data Ingestion & Cleaning Engine**: Validates schemas (`product_id`, `product_name`, `date`, `price`, optional `category`, `discount_percent`), performs temporal sorting, handles missing records, and supports custom user CSV uploads.
  3. **Multi-Model Forecasting Engine**:
     - *Linear Regression*: Extrapolates baseline linear trend over elapsed days.
     - *Holt's Linear Trend (Exponential Smoothing)*: Damped additive trend model capturing momentum and level shifts.

  5. **Interactive Streamlit Web Dashboard**:

     - Dynamic forecast horizon slider (1 to 30 days) with next-day and horizon price estimates (% change).
     - Interactive multi-line charts combining actual history and future projections.
     - Product data explorer and CSV export for selected items.
- **Datasets**: Bundled synthetic historical dataset (3,650 records across 10 diverse tech/consumer electronics categories: Wireless Headphones, Gaming Laptops, Smartwatches, 27-inch Monitors, Portable SSDs, etc.) spanning full yearly cycles, plus live scraped datasets.

  5. *Presentation Layer*: Streamlit UI, metric KPI cards, Plotly/Streamlit charts, CSV downloader.

- **Dataset Schema**: `product_id`, `product_name`, `category`, `date`, `price`, `discount_percent`.

- **Time Representation**: Elapsed days feature transformation $(t - t_0)$ normalized for regression baselines.

- **Data Integrity Constraints**: Mandatory non-negative price bounding (`np.maximum(prediction, 0)`).

  - *Median Ensemble*: Robust aggregation mitigating model-specific variance and outlier risk.

- **Evaluation Metrics**:
